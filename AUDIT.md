# Аудит сайта cloudrepairs.ru и источники содержания

## Ограничение доступа (важно)

При разработке **не удалось открыть ни одну из четырёх страниц оригинального сайта**:

| Способ | Результат |
|---|---|
| Прямой запрос из среды разработки (curl) | `CONNECT tunnel failed, 403` — домен закрыт сетевой политикой окружения |
| WebFetch | `getaddrinfo ENOTFOUND cloudrepairs.ru` (в т. ч. `www.`) |
| Web Archive, archive.ph, r.jina.ai | Недоступны |
| Поисковая выдача (WebSearch по домену cloudrepairs.ru) | Частично: заголовок главной, фрагменты текстов главной и раздела «Обучение и консультация», контакты |

Поэтому полноценный поблочный аудит (структура сверху вниз, изображения, меню, футер,
формы, мобильная версия, типографика оригинала) **провести невозможно**. Ниже — только то,
что удалось проверить, и честные отметки о пробелах. Ничего не придумано.

## Проблемы и улучшения, заложенные в новую версию

Так как оригинал увидеть не удалось, ниже — не проблемы оригинала, а решения новой версии:

| Область | Решение |
|---|---|
| Первый экран | Крупный H1 с ключевой формулировкой, лид, две кнопки (вход в систему / обучение), схема интерфейса (место под оригинальные скриншоты) |
| Возможности | Единая сетка карточек с иконками и нумерацией вместо разрозненных блоков; списки — с маркерами |
| Обучение | Разделение на «Обучение» и «Консультация и сопровождение», навигация-якоря в первом экране, крупные читаемые пункты |
| Навигация | Закреплённая шапка, активный пункт, отдельное полноэкранное мобильное меню (Esc, закрытие при переходе) |
| Контакты | Единый финальный блок на каждой странице + футер |
| SEO | Пререндер каждой страницы в отдельный HTML, title/description/OG/canonical, один H1, sitemap.xml, robots.txt |
| Доступность | Skip-link, видимый фокус, aria-атрибуты, семантические `header/nav/main/section/footer` |
